Lumi · custom icon system

A pencil-soft icon set built for Lumi.

32 icons drawn on a single 24px grid: 1.6px strokes, rounded caps, gentle organic curvature, with a single apricot accent that highlights the meaningful stroke in each glyph. The set echoes the Friendly Modern type voice — soft, optimistic, never clinical.

The system

Drawn once, used everywhere — every icon is a <use> reference.
